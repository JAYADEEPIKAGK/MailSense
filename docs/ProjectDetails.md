# MailSense AI - Project Details

## Project Title
MailSense AI – Intelligent Email Prioritization System for Students

## Problem Statement
Students receive hundreds of emails from colleges, placement cells, clubs, faculty members, and internship portals. Due to information overload, they often ignore or miss important emails containing deadlines, placement opportunities, exam schedules, and workshop information.

## Proposed Solution
MailSense AI is an AI-powered web application that connects with Gmail, identifies important emails, summarizes lengthy content, extracts deadlines, categorizes emails, and sends timely notifications to students.

## Objectives
- Detect important emails automatically.
- Generate AI-powered email summaries.
- Extract deadlines and key information.
- Notify students before important due dates.
- Display all important emails in a clean dashboard.

## Technologies Used
- Frontend: React.js
- Backend: FastAPI (Python)
- Database: MongoDB
- AI: Gemini API
- Authentication: Google OAuth
- Email Integration: Gmail API
- Version Control: Git & GitHub

## Expected Outcome
Students will never miss important college emails and can quickly understand the content without reading lengthy messages.
