# MailSense AI

## 📌 Project Overview
MailSense AI is an AI-powered email prioritization system that helps students identify important college emails, summarize long messages, extract deadlines, and receive reminders.

## 🎯 Problem Statement
Students often ignore important emails due to information overload and long email content, causing them to miss placements, internships, exams, and deadlines.

## 🚀 Features
- Gmail Integration
- AI Email Classification
- AI Email Summarization
- Deadline Extraction
- Smart Notifications
- Dashboard

## 🛠️ Tech Stack
- React.js
- FastAPI
- MongoDB
- Gmail API
- Gemini API
